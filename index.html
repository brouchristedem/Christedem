Installation

Sur l'écran d'accueil, sans passer par un store

MON CV PRO CI, mondocpro, Quizci et Ma Boutique CI s'ouvrent comme des applications, avec leur icône, en plein écran.

Android · ChromeInstaller depuis Chrome

  1. Ouvrez le site dans Chrome.
  2. Appuyez sur le menu ⋮, puis sur Installer l'application.
  3. L'icône apparaît sur votre écran d'accueil.

iPhone · SafariInstaller depuis Safari

  1. Ouvrez le site dans Safari.
  2. Appuyez sur Partager, puis sur Sur l'écran d'accueil.
  3. Validez : l'application est prête.
